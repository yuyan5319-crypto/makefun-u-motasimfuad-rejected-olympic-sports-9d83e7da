A one-line pitch for a rejected Olympic sport: synchronised queueing. Four athletes, one perfect line, four hours of standing still — and the gold medal goes to whoever sighs the least. The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout, refusing to run if the line breaks the 1–200 character, single-line gate rule.

> Synchronised queueing: four athletes hold a perfect line for four hours, and gold goes to whoever sighs the least.

## Run it

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written.
